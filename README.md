# WinMedic

Windows-ის მოვლის, დიაგნოსტიკისა და აღდგენის ერთიანი ინსტრუმენტი — PowerShell-ზე აწყობილი GUI აპლიკაცია სისტემური ადმინისტრატორებისა და IT-სპეციალისტებისთვის.

> **სტატუსი:** ადრეული ეტაპი. პროექტი ეყრდნობა [Windows Maintenance Tool](https://github.com/ios12checker/Windows-Maintenance-Tool)-ს (MIT) და თანდათან გადადის საკუთარ არქიტექტურაზე.

---

## რა არის ეს

WinMedic აერთიანებს იმ ამოცანებს, რომლებიც ჩვეულებრივ გაფანტულია Settings-ში, Control Panel-ში, PowerShell-სა და Registry Editor-ში:

- **პაკეტების მართვა** — winget, Chocolatey, pip, npm და სხვა მენეჯერები ერთი ფანჯრიდან
- **სისტემის ჯანმრთელობა** — SFC, DISM, CHKDSK, დისკის და მეხსიერების დიაგნოსტიკა
- **გაწმენდა** — დროებითი ფაილები, ქეში, ლოგები, ძველი დრაივერები
- **ქსელი** — DNS, firewall, ადაპტერების კონფიგურაცია და დიაგნოსტიკა
- **დრაივერები** — ინვენტარიზაცია, ექსპორტი, ძველი ვერსიების გასუფთავება
- **Tweaks** — სისტემური პარამეტრები revert-ის შესაძლებლობით
- **თემა** — dark/light, პარამეტრები ინახება ლოკალურად

## მოთხოვნები

- Windows 10 / 11
- PowerShell 5.1 ან უფრო ახალი
- ადმინისტრატორის უფლებები (ოპერაციების უმეტესობისთვის)

## გაშვება

```
Start_WMT_GUI.bat
```

ან პირდაპირ PowerShell-იდან:

```
powershell -ExecutionPolicy Bypass -File .\WMT-GUI.ps1
```

> ფაილების სახელები ჯერ კიდევ upstream-ისაა — ისინი გადაერქმევა მას შემდეგ, რაც კოდი მოდულებად დაიშლება (იხ. [ROADMAP](docs/ROADMAP.md)). ამის მიზეზი ისაა, რომ ადრეული გადარქმევა upstream-იდან განახლებების ჩამოტანას ართულებს.

## პროექტის მიმართულება

დეტალური გეგმა: **[docs/ROADMAP.md](docs/ROADMAP.md)**

მოკლედ — სამი ძირითადი ხაზი:

1. **არქიტექტურა.** 44,000-ხაზიანი ერთი `.ps1` ფაილი დაიშალოს მოდულებად, რომ ყოველი ახალი ფუნქცია მარტივად დაემატოს.
2. **ლოკალიზაცია.** ქართული ინტერფეისი, მრავალენოვანი ფენა.
3. **პარკის მართვა.** ერთი მანქანის ინსტრუმენტიდან — ბევრი მანქანის (სკოლა/ოფისი) მოვლის ინსტრუმენტამდე.
