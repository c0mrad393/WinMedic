### ლოკალიზაციის მექანიკა

თარგმანი **არ** ხდება კოდში ტექსტის ჩანაცვლებით. სამი დამჭერი წერტილია:

| ადგილი | რას ფარავს |
|---|---|
| `ConvertTo-WmtLocalizedXaml` | ყველა `Content` / `Text` / `ToolTip` / `Header` / `Title` XAML-ში |
| `Set-ButtonIcon` | ღილაკების წარწერები და tooltip-ები, რომლებიც კოდიდან ინიჭება |
| `Add-SearchIndexEntry` | გლობალური ძებნა — ინდექსში ორივე ენა ხვდება |

გასაღები არის ინგლისური ორიგინალი, ამიტომ:

- ცხრილში არარსებული სტრიქონი უბრალოდ ინგლისურად რჩება — ნახევრად ნათარგმნი ინტერფეისი მუშა ინტერფეისია
- 44,000-ხაზიან ფაილში UI-ის ტექსტები არ შეცვლილა, ანუ `git merge upstream/main` კვლავ მუშაობს

სტრიქონები: `$script:WmtStringsKa` (სექცია `1b. LOCALIZATION`). სკრიპტის გვერდით `i18n/ka.psd1`-ის დადება გადაფარავს ჩაშენებულ ცხრილს — მოსახერხებელია თარგმანზე მუშაობისას.

## Upstream-თან მუშაობა

განახლებების ჩამოსატანად:

```bash
git fetch upstream
git log --oneline HEAD..upstream/main    # რა შეიცვალა
git merge upstream/main                   # ან cherry-pick კონკრეტული commit-ები
```

სანამ ეტაპი 2 დასრულდება, merge შედარებით უმტკივნეულოა. მის შემდეგ ჯობია cherry-pick-ი ან ხელით პორტირება.
