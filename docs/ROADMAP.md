### 4.0 რა არ გააკეთა ამან

ელემენტების რაოდენობა: **1,424 → 1,405**. ეს **1.3%-ია**, და არა წარმადობის გამოსწორება.

ადრე ამ ROADMAP-ში ეწერა, რომ სამომხმარებლო ფუნქციები ხის ~41%-ს იკავებდა. **ეს რიცხვი არასწორი იყო** — პანელების სეგმენტაცია გატყდა და `pnlCatalog`-ში `pnlTweaks` მოხვდა. რეალურად თამაშების ბიბლიოთეკა 33 ელემენტია (2.3%), Gaming ბარათი 14.

ანუ ეს ეტაპი პროდუქტის გაწმენდაა და არა ოპტიმიზაცია. ნამდვილი შეფერხების წყარო ჯერ უცნობია — პასუხს `Write-WmtStartupMark`-ის ჩანაწერები მოგვცემს რეალური მანქანიდან.

## Upstream-თან მუშაობა

განახლებების ჩამოსატანად:

```bash
git fetch upstream
git log --oneline HEAD..upstream/main    # რა შეიცვალა
git merge upstream/main                   # ან cherry-pick კონკრეტული commit-ები
```

სანამ ეტაპი 2 დასრულდება, merge შედარებით უმტკივნეულოა. მის შემდეგ ჯობია cherry-pick-ი ან ხელით პორტირება.
